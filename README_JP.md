## プロジェクト概要

本プロジェクトは、医学画像診断学、インターベンショナルラジオロジー、AI支援解析、マルチモーダル画像技術選択などの中核領域を体系的に統合し、**136 の重要臨床スキル**を **13 の大分類**に整理しています。

**対象読者**：画像診断医、全診療科の臨床医、医学生、インターベンショナルラジオロジーチーム、医学教育者

**参考教科書**：人民衛生出版社『医学画像学』第9版（国家衛生健康委員会「第14次五カ年計画」計画教科書）

**⚠️ リスク ⚠️**：本スキルは、ハイリスクな医療診断、治療、救急、侵襲的処置に関するガイダンスを提供します。これらが独立した臨床アドバイスとして誤用される可能性があります。

**対策**：全てのアウトプットは、教育的または臨床医によるレビューのための参考資料としてのみ使用してください。診断、治療、救急トリアージ、または処置の実施に先立ち、資格のある臨床監督、最新の公式ガイドライン、地域のプロトコル、および専門家によるレビューが必須です。

**⚠️ リスク ⚠️**：医学画像のプロンプトや例には、患者情報や画像メタデータが含まれる可能性があります。

**対策**：組織が許可し、データが適切に匿名化されていない限り、識別可能な患者情報や画像メタデータを入力しないでください。

### 質問戦略

#### 1. **概念検索**

質問：
```bash
Bosniak腎嚢胞分類2019年版の基準
```

回答：
```bash
## Bosniak腎嚢胞分類（2019年版）

Bosniak分類は、腎嚢胞性病変の悪性リスクを評価し、臨床判断（経過観察 vs. 手術）を導くために用いられます。

### 分類基準

| 分類 | 画像所見 | 悪性リスク | 管理 |
|------|---------|-----------|------|
| **I型** | 単純性嚢胞、壁は薄く平滑、隔壁・石灰化・充実成分なし。CTで水様濃度、MRI T₂WIで高信号、造影増強なし | <1% | 良性、無治療 |
| **II型** | 少数（≤3個）の薄壁（≤2mm）隔壁、微細な石灰化または短節の軽度肥厚あり | <5% | 良性、無治療 |
| **IIF型** | 複数（≥4個）の薄壁隔壁、軽度の均一な壁/隔壁肥厚、平滑な肥厚性石灰化、造影増強を示す軟部組織なし | 約10% | 経過観察 |
| **III型** | 1つ以上の充実成分、明らかな造影増強、壁/隔壁の不規則な肥厚（≥4mm） | 約55% | 外科的切除 |
| **IV型** | 明らかな造影増強を示す軟部組織成分（嚢胞性病変の≥25%が充実性） | >90% | 外科的切除 |

### 2019年版の主な更新点
1. **より正確な隔壁数のカウント**：≤3個＝少数、≥4個＝複数
2. **壁/隔壁の厚さの数値化**：≤2mm＝薄壁、≥4mm＝明らかな肥厚
3. **「造影増強を示す軟部組織成分」の評価基準を明確化**
4. **IIF型の経過観察推奨**：初回6～12か月後にCT/MRI、安定していれば2年ごとに延長

> **まとめ**：I型/II型は良性で無治療、IIF型は定期的経過観察、III型/IV型は外科的切除。悪性リスクは充実成分の量に強く相関します。
```

#### 2. **鑑別診断**

質問：
```bash
60歳男性、長期喫煙歴。CTで右上葉に分葉状の腫瘤とspiculation、同側肺門リンパ節腫大を認める
```

回答：
```bash
## 症例分析

| 項目 | 所見 |
|------|------|
| 年齢 | 60歳（肺癌好発年齢） |
| 喫煙歴 | 長期（高危険因子） |
| 病変部位 | 右上葉 |
| 形態 | 分葉状（悪性増殖パターンを示唆） |
| 辺縁 | spiculation（悪性徴候） |
| 随伴所見 | 同側肺門リンパ節腫大 |

### 最も可能性の高い診断

**末梢型肺癌（扁平上皮癌または腺癌を考慮）**

### 診断根拠
1. **臨床的危険因子**：60歳 + 長期喫煙歴
2. **画像上の悪性徴候**：分葉状、spiculation
3. **リンパ節転移**：同側肺門腫大は領域リンパ節浸潤を示唆

### 鑑別診断
- **結核腫**：上葉尖後区域/下葉背側区域に好発、衛星病変・石灰化を認めることがあり、造影で環状増強
- **炎症性偽腫瘍**：辺縁は比較的平滑、感染歴の可能性
- **肺膿瘍**：空洞と液体貯留を認めることがあり、急性発症で感染徴候を伴う

### 推奨される次のステップ
1. 造影CTで病変の血行動態と縦隔リンパ節の状態を詳細評価
2. PET-CTで全身ステージング
3. CTガイド下経皮的肺生検で病理学的確認
```

#### 3. **治療計画**

質問：
```bash
TACE術後の患者に悪心、嘔吐、右季肋部鈍痛、発熱が出現した場合の対応
```

回答：
```bash
## TACE術後化疗栓塞症候群の管理

### 判断
上記症状は **TACE術後化学塞栓症候群（CES）** の典型的な所見です：
- 悪心、嘔吐 — 化学療法薬による消化器反応
- 右季肋部鈍痛 — 塞栓後の肝虚血および炎症反応
- 発熱 — 壊死組織の吸収熱（通常38～39°C）

### 管理計画

| 症状 | 治療 | 注意点 |
|------|------|--------|
| 発熱 | 解熱薬（アセトアミノフェン/イブプロフェン）、物理的冷却 | >39°Cが持続する場合は感染を除外 |
| 疼痛 | WHO三段階除痛ラダー | HCC患者ではNSAIDsを避ける（肝障害リスク） |
| 悪心/嘔吐 | 5-HT₃受容体拮抗薬（オンダンセトロン） | 水分・電解質バランスを補正 |
| 肝保護 | グリチルリチン製剤、還元型グルタチオン | 術後定期的な肝機能モニタリング |

### 緊急精査が必要な合併症
- 激しく持続的に増悪する腹痛 → **肝膿瘍 / 胆囊炎 / 膵炎** を除外
- >39°Cの発熱と悪寒 → **感染性合併症** を除外
- 腹水増加、黄疸増悪 → **急性肝不全** を除外

> **経過の目安**：CESは通常3～7日間持続し、対症療法で徐々に改善します。7日以上続くか症状が進行性に悪化する場合は、合併症の精査が必要です。
```
