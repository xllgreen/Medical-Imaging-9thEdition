## О проекте

Данный проект систематически объединяет ключевые области диагностической медицинской визуализации, интервенционной радиологии, анализа с помощью ИИ и выбора мультимодальных методов визуализации, охватывая **136 ключевых клинических навыков**, сгруппированных в **13 основных категорий**.

**Целевая аудитория**: Врачи-рентгенологи, клиницисты всех специальностей, студенты-медики, бригады интервенционной радиологии, преподаватели медицины

**Учебник-основа**: «Медицинская визуализация», 9-е издание, People's Medical Publishing House (учебник «14-й пятилетки» Национальной комиссии здравоохранения)

**⚠️ Риск ⚠️**: Данный навык предоставляет рекомендации по высокорискованным медицинским диагностике, лечению, неотложной помощи и инвазивным процедурам, которые могут быть ошибочно использованы как независимая клиническая консультация.

**Меры смягчения**: Используйте все выходные данные исключительно в качестве образовательных справочных материалов или материалов для рецензирования клиницистом. Квалифицированный клинический надзор, действующие официальные руководства, локальные протоколы и экспертная оценка обязательны перед постановкой диагноза, лечением, неотложной сортировкой или проведением процедур.

**⚠️ Риск ⚠️**: Промпты или примеры медицинской визуализации могут содержать информацию о пациентах или метаданные изображений.

**Меры смягчения**: Если это не разрешено вашей организацией и данные не были надлежащим образом деидентифицированы, избегайте ввода идентифицируемой информации о пациентах или метаданных изображений.

### Стратегии запросов

#### 1. **Запрос концепции**

Вопрос:
```bash
Критерии классификации кист почек Bosniak 2019 года
```

Ответ:
```bash
## Классификация кист почек Bosniak (обновление 2019 г.)

Классификация Bosniak оценивает риск злокачественности кистозных поражений почек для принятия клинических решений (наблюдение vs. хирургия).

### Критерии классификации

| Класс | Характеристики визуализации | Риск злокачественности | Тактика |
|-------|----------------------------|------------------------|---------|
| **I** | Простая киста, тонкая гладкая стенка, нет перегородок, кальцинатов или солидных компонентов; водная плотность на КТ, гиперинтенсивный сигнал на T₂-ВИ МРТ, нет накопления контраста | <1% | Доброкачественно, лечение не требуется |
| **II** | Несколько (≤3) тонких (≤2 мм) перегородок; возможны мелкие кальцинаты или короткий сегмент умеренного утолщения | <5% | Доброкачественно, лечение не требуется |
| **IIF** | Множественные (≥4) тонкие перегородки; лёгкое равномерное утолщение стенки/перегородок; гладкие толстые кальцинаты; нет накапливающих контраст мягкотканных компонентов | ~10% | Наблюдение |
| **III** | Один или несколько солидных компонентов с чётким накоплением контраста; неравномерное утолщение стенки/перегородок (≥4 мм) | ~55% | Хирургическое иссечение |
| **IV** | Накапливающий контраст мягкотканный компонент (≥25% кистозного поражения составляет солидная ткань) | >90% | Хирургическое иссечение |

### Ключевые обновления 2019 года
1. **Более точный подсчёт перегородок**: ≤3 = несколько, ≥4 = множественные
2. **Количественная оценка толщины стенки/перегородок**: ≤2 мм = тонкая, ≥4 мм = выраженное утолщение
3. **Уточнены критерии «накапливающих контраст мягкотканных компонентов»**
4. **Рекомендация по наблюдению для класса IIF**: первый контроль КТ/МРТ через 6–12 месяцев, затем при стабильности — каждые 2 года

> **Резюме**: Классы I/II доброкачественны — лечение не требуется; класс IIF требует регулярного наблюдения; классы III/IV — хирургическое иссечение. Риск злокачественности сильно коррелирует с объёмом солидных компонентов.
```

#### 2. **Дифференциальная диагностика**

Вопрос:
```bash
Мужчина 60 лет, длительный стаж курения. На КТ — дольчатое образование в верхней доле правого лёгкого с лучистостью и гомолатеральной хиларной лимфаденопатией.
```

Ответ:
```bash
## Анализ случая

| Параметр | Характеристика |
|----------|----------------|
| Возраст | 60 лет (пик заболеваемости раком лёгкого) |
| Стаж курения | Длительный (фактор высокого риска) |
| Локализация | Верхняя доля правого лёгкого |
| Морфология | Дольчатая (указывает на злокачественный рост) |
| Край | Лучистость (признак злокачественности) |
| Сопутствующие признаки | Гомолатеральная хиларная лимфаденопатия |

### Наиболее вероятный диагноз

**Периферический рак лёгкого (рассмотреть плоскоклеточный рак или аденокарциному)**

### Диагностические основания
1. **Клинические факторы риска**: 60 лет + длительное курение
2. **Злокачественные признаки визуализации**: дольчатость, лучистость
3. **Лимфогенное метастазирование**: гомолатеральное увеличение хиларных узлов указывает на регионарное поражение

### Дифференциальные диагнозы
- **Туберкулома**: Преимущественно в задне-верхушечном сегменте верхней доли / дорсальном сегменте нижней доли; возможны сателлитные очаги, кальцинаты, кольцевидное накопление контраста
- **Воспалительная псевдоопухоль**: Относительно ровные контуры; возможен анамнез инфекции
- **Абсцесс лёгкого**: Возможна полость с уровнем жидкости; острое начало с клиническими признаками инфекции

### Рекомендуемые следующие шаги
1. КТ с контрастированием для оценки васкуляризации и состояния медиастинальных лимфоузлов
2. ПЭТ-КТ для системного стадирования
3. Чрескожная биопсия лёгкого под КТ-наведением для патологоанатомического подтверждения
```

#### 3. **План лечения**

Вопрос:
```bash
Пациент после TACE с тошнотой, рвотой, тупой болью в правом подреберье и лихорадкой. Как действовать?
```

Ответ:
```bash
## Ведение постаблационного синдрома после TACE (химиоэмболизации)

### Оценка
Симптомы соответствуют типичной картине **постэмболизационного синдрома (ПЭС) после TACE**:
- Тошнота, рвота — желудочно-кишечная реакция на химиопрепараты
- Тупая боль в правом подреберье — постишемическое воспаление печени
- Лихорадка — резорбтивная лихорадка (обычно 38–39 °C)

### План ведения

| Симптом | Лечение | Примечания |
|---------|---------|------------|
| Лихорадка | Антипиретики (парацетамол/ибупрофен), физическое охлаждение | При персистирующей >39 °C исключить инфекцию |
| Боль | Трёхступенчатая анальгетическая лестница ВОЗ | Избегать НПВП у пациентов с ГЦК (риск поражения печени) |
| Тошнота/рвота | Антагонисты 5-HT₃-рецепторов (ондансетрон) | Коррекция водно-электролитного баланса |
| Гепатопротекция | Препараты глицирризиновой кислоты, восстановленный глутатион | Послеоперационный мониторинг функции печени |

### Осложнения, требующие срочного обследования
- Сильная, прогрессивно усиливающаяся боль в животе → исключить **абсцесс печени / холецистит / панкреатит**
- Лихорадка >39 °C с ознобом → исключить **инфекционные осложнения**
- Нарастание асцита, усиление желтухи → исключить **острую печёночную недостаточность**

> **Типичное течение**: ПЭС обычно длится 3–7 дней и постепенно разрешается на фоне симптоматической терапии. При сохранении симптомов более 7 дней или их прогрессивном ухудшении требуется дополнительное обследование для исключения осложнений.
```
